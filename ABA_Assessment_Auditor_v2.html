Cada tarjeta muestra un hallazgo con la página del PDF, el fragmento citado y, cuando aplica, un texto sugerido en recuadro verde listo para copiar y pegar en su assessment de Word. Los botones de cada tarjeta no modifican el assessment original: solo cambian el estado del hallazgo en este reporte.
  • Ya corregí esto: usted ya hizo el cambio en el assessment original.
  • Mantener con justificación: deja el texto como está y registra el motivo clínico en el reporte.
  • Falso positivo: el sistema lo marcó por error.
Flujo de corrección: Apruebe → genere → revise en Word aceptando o rechazando cada cambio.

About this tool

ABA Assessment Auditor v2.0 is a standalone document audit tool for ABA assessments and reassessments. It operates locally in your browser; the only outbound connection is to the Anthropic Claude API for conceptual audit checks and document classification.

Mode D (v2.0): deep clinical and Florida Medicaid compliance audit. Receive a document from an analyst, audit it for compliance with CASP, Florida Medicaid, and BACB standards, and generate a report for return.

Future versions will add wizards for Modes A (initial assessment from scratch), B (initial from transfer), and C (reassessment).

Data is stored in your browser's local storage. Use Backup regularly to avoid data loss. The tool never transmits patient data anywhere except to the Claude API for conceptual checks.
